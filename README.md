# The Dynasty & Civilization Challenge Website

This is a simple static website with three pages:

- `index.html` — challenge overview
- `taxes.html` — treasury and weekly tax tracker
- `chapters.html` — full Chapter I information and interactive checklist

## How to use it

Open `index.html` in a browser, or upload all files to the root of a GitHub Pages repository.

The tax tracker and chapter checklist save progress with `localStorage`, meaning progress stays in the same browser on the same device. It is not connected to an account or cloud database yet.

## Files

- `index.html`
- `taxes.html`
- `chapters.html`
- `styles.css`
- `taxes.js`
- `chapters.js`

## Tax settings

The default tax rate is §100 per outside household. Players can change it directly on the Treasury page.
